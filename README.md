# enya.stats-from2026

塩冶オールスターズ スタッツ

塩冶オールスターズ（U10/U12ミニバスケットボールチーム）の
試合スタッツ・シーズン管理・大会成績・選手成長分析を行うPWAアプリです。

## 主な機能

- 試合ごと・大会ごと・期間指定・全試合平均のスタッツ集計
- 対戦チーム分析（スカウティング）
- 月間アワード・シーズンランキング・通算記録
- 選手成長分析（レーダーチャート・トレンド）
- 秋季優勝へ向けたシーズン進行管理
- 管理者エリア（PIN保護：選手の調子・詳細比較・試合サマリー・シミュレーション）
- 表示設定（テーマ手動切替・文字サイズ・キャッシュクリア）
